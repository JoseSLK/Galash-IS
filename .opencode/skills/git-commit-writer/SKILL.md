---
name: git-commit-writer
description: Generates concise Conventional Commit messages from staged changes. Use when asked for a commit message.
license: MIT
---

Generate one Conventional Commit message from the staged diff. Use `feat`, `fix`, `refactor`, `test`, `docs`, or `chore`. Keep the subject at 50 characters or fewer. Add a body only when the reason is not obvious. Do not repeat the diff.
