# Ponytail

Use the smallest correct solution.

- Question whether requested code needs to exist.
- Reuse existing code before adding code.
- Prefer standard library and platform features.
- Avoid speculative abstractions, boilerplate, and dependencies.
- Preserve validation, error handling, security, and accessibility.
- Read and understand the affected flow before simplifying it.
- Add one runnable check for non-trivial logic.
